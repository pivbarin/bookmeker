# sports-betting (n8n)

Спортивные betting-прогнозы на n8n: двухступенчатая схема с экономией на платном API — локальный Ollama (Qwen) предварительно отбирает матчи, платный DeepSeek анализирует только отобранные.

## Воркфлоу

| Файл | Спорт | Статус |
|---|---|---|
| `sports-betting-basketball-v4.json` | Баскетбол (NBA + Единая лига ВТБ) | Актуальный |
| `sports-betting-v3.json` | Футбол (топ-лиги) | Готов, на паузе до сезона |

## Схема (баскетбол v4)

1. **Матчи на сегодня (баскет)** — api-sport.ru v2, матчи на сегодня (`page_size=500`)
2. **Фильтр NBA и ВТБ** — только `notstarted`, NBA/ВТБ, ближайшие 48 ч, максимум 8 матчей
3. **Краткая статистика** — детали с `with_pregame=true`
4. **Сборка промпта** → **qwen3.5:4b** (локальный Ollama, бесплатно) — отбор 2–3 самых предсказуемых матчей
5. **Извлечение матчей** — парсинг номеров, фолбэк на первые 3 при мусорном ответе
6. **Детали матча** — `with_pregame=true&with_bk_odds=true`: полная линия всех букмекеров
7. **Сборка промпта1** — все базовые рынки + рынки PARI/BETBOOM/MELBET и др., форма, H2H, серии, травмы (обрезка блока по 9000 символов)
8. **DeepSeek API** (routerai.ru, платно) — выбирает ОДИН рынок на матч, кэф 1.30–1.90
9. **Сборка экспресса** — перебор пар/троек из разных матчей, итог > 3.0, фолбэк на одиночную
10. **Финальный ответ**

### Защита от лотерейных рынков (v4)

Запрещены рынки, у которых исход почти случаен: чет/нечет, точный счет, точное количество очков, интервалы очков, «кто наберет первым», мультикол-во, мультисчет. Запрет на трёх уровнях:

- системный промпт DeepSeek;
- задача в user-промпте («Сборка промпта1»);
- код-фильтр в «Сборке экспресса» (регэксп, поле `dropped_lottery` в результате показывает, сколько ставок отсеяно).

## Установка

1. Импортируйте JSON в n8n (Workflows → Import from File).
2. Вставьте ключи (в JSON стоят плейсхолдеры):
   - `ВСТАВЬТЕ_КЛЮЧ_API_SPORT` — в 3 узла: «Матчи на сегодня (баскет)», «Краткая статистика», «Детали матча» (заголовок `Authorization`, без Bearer);
   - `ВСТАВЬТЕ_КЛЮЧ_ROUTERAI` — в узел «DeepSeek API» (`Bearer ВСТАВЬТЕ_КЛЮЧ_ROUTERAI`).
   - Рекомендуется хранить ключи в n8n Credentials, а не в узлах.
3. Проверьте, что Ollama доступна на `http://192.168.11.199:11434` и модель называется `qwen3.5:4b` (`ollama list`).
4. Запустите вручную и проверьте прохождение по узлам.

## Что проверить на первом реальном прогоне

- Названия полей кэфов в ответе вашего тарифа api-sport.ru (`choices` / `decimal` / `value`).
- Фактическое название ВТБ-лиги в API (фильтр ищет подстроку «Единая лига ВТБ»).
- Доступность модели `deepseek/deepseek-v4.1-flash` на routerai.ru.

Если «Фильтр NBA и ВТБ» возвращает «Нет предстоящих матчей» при наличии игр — посмотрите сырой ответ в узле «Матчи на сегодня (баскет)» и поправьте `LEAGUES` под реальные названия турниров.
